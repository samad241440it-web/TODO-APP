# GlassTodo 🎯

A modern, glassmorphism-styled Todo app built with vanilla HTML, CSS & JavaScript.

## Features
- ✨ Full CRUD operations
- 💾 LocalStorage persistence
- 🎨 Glassmorphism UI with animations
- 🔍 Filter tasks (All / Active / Completed)
- 📊 Live progress ring
